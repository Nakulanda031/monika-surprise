# Monika — A Little Secret ✨🎂

A personalized birthday surprise experience crafted with interactive animations, romantic piano instrumental background music, cute sound effects, and secret notes.

🌐 **Live Website:** [https://nakulanda031.github.io/monika-surprise/](https://nakulanda031.github.io/monika-surprise/)

---

## ✨ Features

- **Cinematic Welcome & Night Sky:** Dreamy deep purple night sky with floating hearts, twinkling stars, and soft glows.
- **Birthday Countdown:** Real-time countdown to the special day.
- **Interactive Balloon Game:** Poppable balloons with confetti bursts and cute bubble-pop & sparkle sounds.
- **Photo & Video Memories:** Curated gallery with lightbox viewer and video memories.
- **Secret Notes:** Unlockable envelopes with fairy-dust chimes.
- **Emotional Final Reveal & Message:** Heartfelt birthday wish and secret confession.
- **Background Music Player:** Soft romantic piano soundtrack (*Heartwarming* by Kevin MacLeod) with gentle fade-in, volume slider, and independent mute controls.
- **Synthesized Sound Effects:** Built-in Web Audio API sound palette (button clicks, balloon pops, magical chimes, and gallery clicks) with a separate sound toggle.

---

## 🚀 How to Run Locally

1. **Standalone Offline File:** Double-click `monika-surprise-single-file.html` to open in any web browser without needing a server or internet connection.
2. **Local HTTP Server:**
   ```bash
   python -m http.server 5173
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.
3. **Editable React Source Code:**
   Located in the `source/` folder.
   ```bash
   cd source
   npm install
   npm run dev
   ```
